# 花生壳免费版：给 DSH Remote 配固定 HTTPS 域名（国内，免 VPN）

适合没有公网 IP 的电脑。花生壳免费版提供：固定壳域名 + HTTPS 443 映射（自动证书），
限制约 1Mbps、每月 1GB 流量。轻量远程操作 DSH 够用；流量不够再升级套餐。

## 第一步：注册账号 + 实名认证（必须本人，约 5 分钟）

1. 电脑浏览器打开 https://hsk.oray.com/ ，右上角「注册」；
2. 用手机号注册，填验证码、设置密码；
3. 登录后在「帐号 / 实名认证」完成实名认证（姓名 + 身份证号）；
   - 贝锐花生壳的穿透服务要求实名后才能使用，这是监管要求。

## 第二步：安装 Windows 客户端

1. 打开 https://hsk.oray.com/download/ ，点「免费下载」（Windows）；
2. 安装并启动「花生壳」客户端，用刚注册的账号登录。

## 第三步：创建 HTTPS 映射到 DSH Remote 网关

在花生壳客户端里：

1. 进入「内网穿透」→「添加映射」；
2. 应用名称：`DSH Remote`
3. 映射类型：选 **HTTPS**（免费版支持，443 端口、自动签发证书）
4. 内网主机：`127.0.0.1`
5. 内网端口：`8082`
6. 外网域名：选系统分配的**免费壳域名**（形如 `xxx.gnway.cc`，固定不变）
7. 保存。

客户端会显示公网地址：`https://你的壳域名`

## 第四步：把域名告诉 dsh-remote

拿到 `https://你的壳域名` 后：

- **iPhone**：Safari 打开该地址 → 输入口令 → 分享 → 添加到主屏幕（地址永久固定，以后不用重加）；
- **安卓**：dsh-mobile-app APK 里填 `https://你的壳域名/mobile`；
- 电脑侧无需改任何配置：花生壳把 443 转发到本机 8082，后面就是 dsh-remote 登录网关。

## 第五步：让花生壳开机自启

1. 花生壳客户端设置里勾选「开机自动启动 / 自动登录」；
2. 或手动把花生壳快捷方式放入启动目录：
   `shell:startup` 文件夹里放客户端快捷方式。

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机打不开域名 | 确认电脑上 dsh web(3080)、dsh-remote 网关(8082)、花生壳客户端都在线 |
| 提示流量用尽 | 免费版每月 1GB；下月自动恢复，或升级套餐 |
| HTTPS 映射选项灰色 | 先完成实名认证；或咨询花生壳客服 |
| 端口填错 | 一定是 8082（网关），不是 3080 |
